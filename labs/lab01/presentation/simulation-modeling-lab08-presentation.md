# Содержание исследования

## Язык программирования Julia

- Высокоуровневый динамический язык для научных вычислений
- **Множественная диспетчеризация** — выбор метода по типам всех аргументов
- **JIT-компиляция** через LLVM — производительность компилируемых языков
- **Динамическая типизация** с возможностью явного указания типов
- Богатая система типов: `Int8`…`Int128`, `UInt8`…`UInt128`, `Float16`/`Float32`/`Float64`, `Complex{T}`, `Bool`

## Интерактивные блокноты Jupyter

- Документ формата `.ipynb` (JSON), объединяющий текст, код и результаты
- **Ячейка** — фрагмент текста (Markdown) или кода (Code)
- **Ядро** — вычислительный бэкенд (`IJulia`)
- **Командный режим** (`Esc`) — навигация и операции над ячейками
- **Режим редактирования** (`Enter`) — ввод содержимого
- Горячие клавиши: `Shift+Enter` — выполнить, `a`/`b` — вставить, `x` — удалить, `m`/`y` — режим

## Система типов Julia

- Иерархия числовых типов:
  - `Number` → `Real` → `Integer` → `Int8`, `Int16`, `Int32`, `Int64`, `Int128`, `UInt8`…`UInt128`
  - `Number` → `Real` → `AbstractFloat` → `Float16`, `Float32`, `Float64`
  - `Number` → `Complex{T}`
- Диапазоны целых типов:
  - `Int8`: [−128, 127]
  - `Int16`: [−32 768, 32 767]
  - `Int32`: [−2 147 483 648, 2 147 483 647]
  - `Int64`: [−9 223 372 036 854 775 808, 9 223 372 036 854 775 807]
  - `UInt8`: [0, 255]
  - `UInt64`: [0, 18 446 744 073 709 551 615]

## Функции ввода-вывода

- `print(x)` / `println(x)` — вывод без/с переводом строки
- `show(x)` — компактное представление значения
- `write(io, x)` — запись в поток
- `read(io, T)` — чтение из потока в тип `T`
- `readline(io)` / `readlines(io)` — чтение одной строки / всех строк
- `readdlm(path, delim)` — чтение таблицы с разделителями
- `parse(T, s)` — преобразование строки в тип `T`
