# Содержание исследования

## Общие функции для структур данных

- `isempty()` — проверяет, пуста ли структура данных
- `length()` — возвращает длину структуры данных
- `in()` — проверяет принадлежность элемента к структуре
- `unique()` — возвращает коллекцию уникальных элементов
- `reduce()` — свёртывает структуру по заданному бинарному оператору
- `maximum()` / `minimum()` — наибольший / наименьший результат вызова функции

## Кортежи

- Неизменяемая индексируемая последовательность элементов
- Индексация с единицы
- Синтаксис: `(element1, element2, ...)`
- Бывают именованные: `(a=2, b=1+2)`
- Обращение к элементам: по индексу `x[1]` или по имени `x.a`
- Проверка вхождения: `in("tmp", x2)`, `0 in x2`

## Словари

- Неупорядоченный набор связанных по ключу данных
- Синтаксис: `Dict(key1 => value1, key2 => value2, ...)`
- Методы: `keys()`, `values()`, `pairs()`, `haskey()`
- Добавление элемента: `phonebook["Сидоров П.С."] = "555-3344"`
- Удаление ключа: `pop!(phonebook, "Иванов И.И.")`
- Объединение словарей: `merge(a, b)`

## Множества

- Неупорядоченная совокупность элементов какого-либо типа
- Синтаксис: `Set([itr])`
- Объединение: `union(S1, S2)`
- Пересечение: `intersect(S1, S3)`
- Разность: `setdiff(S3, S1)`
- Проверка вложенности: `issubset(S1, S4)`
- Проверка эквивалентности: `issetequal(S3, S4)`
- Изменение: `push!(S4, 99)`, `pop!(S4)`

## Массивы

- Коллекция упорядоченных элементов в многомерной сетке
- Вектор-строка: `[1 2 3]`; вектор-столбец: `[1, 2, 3]`
- Многомерные: `rand(2, 3)`; трёхмерные: `rand(4, 3, 2)`
- Пустые: `[]`, `(Int64)[]`, `(Float64)[]`
- Генерация через включение: `[sqrt(i) for i in 1:10]`
- Операции: `sort(ar, dims=1)`, `ar .> 14`, `findall(ar .> 14)`
